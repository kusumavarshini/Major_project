12. DETAILED DISCREPANCY AUDIT & ROOT CAUSES
------------------------------------------------------------------------------------------
DISCREPANCY 1: 'genuine_matched_minutiae' Column Value Recorded as 0 Across All Rows
  - Files Affected: before_rectification_results.csv (Col 7, 42 rows)
                    after_rectification_results.csv (Col 7, 42 rows)
                    genuine_scores.csv (Cols 5 & 8, 42 rows)
  - Observed: All 42 rows have genuine_matched_minutiae = 0.
  - Root Cause: In evaluate_fingersure_mysql.py (line 203), the script queried:
       genuine_minutiae = int(genuine_cand.get('matched_minutiae_count', 0))
       However, matcher.identify_1toN() stores this value under the dictionary key
       'matched_minutiae' (not 'matched_minutiae_count'). As a result, the default 0 was returned.
  - Impact: Purely informational metadata. Does NOT affect matching raw_score, rank,
            genuine_decision, Top-1/Top-5 accuracy, FRR, or FAR.

DISCREPANCY 2: Row Sequence Difference Between Per-Query Results and Paired Files
  - Files Affected: before_rectification_results.csv / after_rectification_results.csv (Rows 15 to 42)
                    vs. paired_comparison.csv / genuine_scores.csv (Rows 15 to 42)
  - Observed: Rows 1-14 have identical sequence. Starting at row 15, ordering diverges.
  - Root Cause: Windows filesystem Path.glob() sorts names case-insensitively:
       'Ganesh_...' -> 'harshitha_...' -> 'issa_...' -> 'jyothika_...' -> 'Kusuma_...'
       In contrast, paired_comparison.csv sorts identities using Python's standard string sort:
       sorted(dist_map.keys()), which is ASCII case-sensitive ('A'..'Z' before 'a'..'z').
       Therefore, all uppercase identities (Kusuma, Lakshmi, Mangalamma, Neha, Priyanka, Sanjana)
       appear before lowercase identities (harshitha, issa, jyothika, manal, manya, shuban, sushmitha, thryaee).
  - Impact: Zero impact on metrics or correctness. All paired rows look up counterparts by
            exact dictionary identity string; each identity is paired with 100% precision.

DISCREPANCY 3: Top-1 Accuracy Delta Rounding Precision Difference (0.01%)
  - Files Affected: evaluation_summary.csv (Row 10, Col 4)
  - Observed: Reported Difference is -4.77%, whereas exact fraction difference is -4.76%.
  - Root Cause: Top-1 Before is 16/42 = 38.0952% (rounded to 38.10%).
       Top-1 After is 14/42 = 33.3333% (rounded to 33.33%).
       Subtracting pre-rounded values yields: 33.33% - 38.10% = -4.77%.
       Subtracting exact fractions yields: (14 - 16)/42 = -2/42 = -4.7619% (-4.76%).
  - Impact: Negligible 0.01% floating-point display rounding artifact.
